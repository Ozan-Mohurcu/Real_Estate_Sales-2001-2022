Real Estate Sales Dataset 🏡

📝 Overview
This dataset contains information about real estate sales, including various properties' features and their corresponding sale prices. The goal is to analyze the relationship between property attributes and their selling prices. This dataset is ideal for regression and prediction models.

🔍 Analysis Goals
The following analyses can be performed with this dataset:

Examining the relationship between property features (such as square footage, number of rooms, location) and sale price.
Building regression models to predict property prices based on available attributes.
Identifying trends in the real estate market by analyzing sales data over time.

📊 Dataset Features
Date: Date when the property was sold.
Price: Sale price of the property.
Bedrooms: Number of bedrooms.
Bathrooms: Number of bathrooms.
Square Feet: The size of the property in square feet.
Location: Location of the property.
Year Built: Year the property was built.
